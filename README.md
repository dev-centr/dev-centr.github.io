## About

This repository publishes the organization root at `https://dev-centr.github.io/`. It is intentionally minimal:

- [`robots.txt`](robots.txt) — host-wide crawler policy with `Sitemap:` lines for known project Pages
- [`sitemap.xml`](sitemap.xml) — sitemap index pointing at project sitemaps on this host
- [`index.html`](index.html) — brief pointer to the primary org site and docs hub

Product docs and demos live in their own repositories under this host (for example PackageHub, Stack Advisor, Equivalence Engine docs).
